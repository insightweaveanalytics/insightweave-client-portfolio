## Selected portfolio demos

### Invoice text to a review-ready CSV
A local demo extracts labeled invoice fields, checks required values and duplicates, and lists exceptions for human review. Its four fictional samples produce three ready records and one flagged record with a missing total. The valid sample total is INR 37,749.50.

[View the invoice demo source](https://github.com/insightweaveanalytics/automated-invoice-processing-demo/tree/main/end-to-end-demo)

**Scope:** labeled text files only. It does not read PDF or image files or perform OCR. This is a portfolio demo, not client work or a production accounting system.

### Support-ticket triage with NLP
A Google Colab-ready prototype uses a generated dataset of 720 fictional messages to explore topic and sentiment classification, baseline evaluation, and error review. The notebook and CSV are included in the package below.

[Download the complete portfolio and demo package](https://github.com/insightweaveanalytics/insightweave-client-portfolio/raw/refs/heads/main/insightweave-client-portfolio.zip)

**Scope:** synthetic data and baseline models; not validated for real customer conversations.
